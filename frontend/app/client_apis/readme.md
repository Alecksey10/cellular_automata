#### О конфигурации

Конфигурация может содержать:

* переменные значений
  * строковые, численные, булевы
* UI инструменты для их редактирования
  * input, combobox, scroller, radiobutton, checkbox
* имя/название конфигурации
* описание конфигурации

При смене параметра конфигурации в GUI следует вызов смены её в автомате
При этом, не все параметры редактируемые, некоторые используются для вызова событий? например, runAction с именем вызываемого метода

метод отдачи конфигураций, к небольшому сожалению, подразумевает дублирование, ну или можно генерировать её.
